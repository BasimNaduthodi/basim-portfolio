# Basim N — portfolio

A static site: `index.html` plus the `img/` folder. No build step.

## Netlify
Drag this whole folder (or the zip) onto https://app.netlify.com/drop — done.
Or: New site → Import from Git → publish directory `.`

## Vercel
https://vercel.com/new → upload / import this folder → Framework preset: **Other** → Deploy.

## Notes
- The "Ask my AI" chat uses Claude only when the page runs inside claude.ai.
  On Netlify/Vercel it automatically uses its built-in answers about Basim's
  work, so it still works with no API key.
- To update a photo or logo, replace the file in `img/` with the same name.
